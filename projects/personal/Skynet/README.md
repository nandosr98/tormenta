# Skynet

Proyecto interno: agente IA para optimizar operación Scrum con Jira + GitLab + Microsoft Teams.

## Estructura
- 00-input: prompts, requisitos y contexto bruto
- 01-vision: objetivos, alcance y propuesta de valor
- 02-architecture: diseño técnico e integraciones
- 03-automation-catalog: automatizaciones priorizadas
- 04-roadmap-business-case: roadmap, propuesta de negocio y business case
